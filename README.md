Entry for make.fun's "Get the most reposts and likes on make.fun's newest X posts" bounty. The entry itself is a set of posts on X, each a quote of or a direct reply to a different recent post by @makefunai, listed in POSTS.json at the repository root. The program in main.ts (Node 22, standard library only) simply copies POSTS.json to /output, which is all the harness asks of it; scoring reads the X posts themselves (2 points per repost or quote, 1 point per like).

## Run it

```sh
node main.ts
```
